# Groundwork audit remediation

Implementation date: 29 October 2026. Baseline: `1a4a2b72194dedc5b2d98b1dffb4ba14b8dcc0bc` (the inspected deployment). Work is isolated on `codex/audit-priority-fixes`.

This records the response to the 28 October application/AEC audit. It describes source changes and bounded verification, rather than claiming that the live deployment, infrastructure, every security boundary or engineering method has been audited. No production data, subscription, permissions or native-worker configuration was changed.

## Release status

The immediate product-transparency and reliability fixes are implemented. Groundwork is presented as a concept-design and preliminary-review workspace. Construction use, independently validated engineering and general interoperability remain separate release gates. Labeling a limitation correctly does not implement the missing capability.

## Verification evidence

Final verification passed `npm run lint`, `npm run build` and the complete `npm test` command: **313 passing tests** (155 server, 120 client, 12 studio, 2 mail-setup and 24 operations). New coverage includes session-outage/401 handling, active-session filters, cache boundaries/replacements/snapshots/protection/blocked-open handling, exported-page classification and readable text color, omitted CAD geometry disclosure, DWG-readiness retry/cancellation, unit conversions, deferred decoration and explicit offline preparation. The integrated build preflight, isolated PostgreSQL-engine API flow and bounded SQLite/PostgreSQL-engine capacity checks also passed. These are synthetic local checks; they do not measure production latency or constitute a live managed-database audit.

The first restricted-environment test attempt could not connect to its own temporary local servers; the complete suite then passed with local-network access. That initial environmental failure is not recorded as an application defect. Final browser checks used a disposable local SQLite workspace and synthetic account, without production credentials or data: mobile signup/email verification, project creation, eight-object starter frame, save/reopen, metre-to-millimetre display, exact property edit/undo, guided GPa input/calculation, optional offline preparation and PDF download. The nine-page PDF was rendered for visual inspection; every page retained its output-limit stamp. Screenshots and exported QA documents belong to that local fixture.

Passing these checks does not establish live tenant isolation, cookie/deployment configuration, provider data handling, backup recoverability, legal compliance, full accessibility, field performance or certified engineering accuracy.
