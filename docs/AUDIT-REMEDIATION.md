This records the response to the 28 October application/AEC audit. It distinguishes implemented source changes and bounded verification from live deployment configuration, professional approval and operator decisions. No production data, subscriptions or permissions were changed. A tested branch does not establish that the public deployment has received its changes.

## Implemented changes and acceptance boundaries

Groundwork remains a concept-design and preliminary-review workspace. The implementation now includes physical-scale CAD drawing projections, explicit vertical section cuts, external IFC geometry acceptance and numerical reference cases. These capabilities have executable checks; they do not confer construction approval, national-code compliance or general interoperability.

## Verification evidence

The complete application suite passes **346 tests**: 155 server, 153 client, 12 studio, 2 mail-setup and 24 operations. `npm run lint` and `npm run build` pass. The integrated build preflight, isolated PostgreSQL-engine API flow and bounded SQLite/PostgreSQL-engine capacity checks have also passed. These are synthetic checks, not production latency measurements or an audit of the live managed database.

Drawing regressions check known physical PDF lengths (a 10 m span measures 100 mm at 1:100), cardinal orientation, resolved elevations/levels, real section intersections, wall openings, explicit NTS, oversized drawing rejection, coverage, page classification and text color. A section requires an explicitly authored finite plane coordinate and a compatible look direction; the application does not silently substitute an elevation. PDF review fixtures were rendered for visual inspection.

The external IFC acceptance validates seven measured products in the canonical fixture using IfcOpenShell's schema validator and geometry kernel, then compares identity and geometry after external write/reopen. It checks both filled and unfilled wall openings, a rotated column and wall, an analytic circular column, a concave slab, a legacy wall and the room space. The complete file is schema-checked; the seven products define the measured geometry scope. Nine engineering cases compare solver outputs with independent closed-form equations and equilibrium/conservation checks. Neither suite changes project reports to a professionally verified state.

Browser checks use a disposable local SQLite workspace and synthetic account, without production credentials or data. Verified paths include mobile signup, project creation, starter geometry, save/reopen, metre/millimetre display, exact property edit/undo, guided GPa calculation, optional offline preparation, keyboard element placement and PDF download. Earlier restricted-environment attempts could not connect to their temporary local servers; passing reruns used local-network access. That environment restriction is not counted as an application defect.

Passing these checks does not establish live tenant isolation, provider data handling, production backup recoverability, legal compliance, full accessibility, field performance or certified engineering accuracy.
