# Indian gravity and wind combination subset

`client/src/lib/nationalLoadRecipes.ts` generates a bounded IS 456:2000 Table 18 factor subset for explicitly authored reinforced-concrete characteristic actions. It does not calculate structural response. The workbench exposes **National load combinations** and lets the user copy a supported generated draft to the 3D frame module for further editing and analysis.

The inspected primary artifact is the [BIS-authored IS 456:2000 April 2007 reprint](https://law.resource.org/pub/in/bis/S03/is.456.2000.pdf), including Amendments 1/2. Clause 36.4.1 and Table 18 supply the collapse families: 1.5(DL+IL), 1.5(DL+WL), 1.2(DL+IL+WL), and 0.9DL+1.5WL where reduced restoring dead action is relevant. Optional short-term serviceability families are DL+IL, DL+WL and DL+0.8IL+0.8WL. The correction to Table 18's absent wind entry for DL+IL is respected. Long-term creep and special-consequence higher factors are excluded.

Version 1 inputs contain a bounded existing `FrameModel3D`, one `deadCaseId`, one `imposedCaseId`, zero to three `windCaseIds`, source declaration, explicit characteristic-action confirmation, amendment-scope confirmation/review source, and stability/serviceability options. Every model case must be mapped exactly once; unsupported extra action types cannot be silently omitted. The dead/imposed cases already aggregate their intended characteristic actions. Each wind case is a complete independently supplied pattern; direction, pressure pairing and opposite signs are never inferred. Geometry/material values and original combinations remain in captured source provenance. Generated combinations replace the original combinations in an independent draft, with at most 17 combinations.

Generation requires the current country-basis profile, country IN, a complete confirmed reviewed basis and exactly one catalog IS 456:2000 concrete adoption with its local amendments. Unsupported countries, editions or incomplete declarations produce `unsupported-basis`, no generated frame and no factors. They retain the chosen basis. Adoption/amendment confirmation records an explicit project review, rather than automatic verification that a later amendment matches this historical reprint.

Linked-project import copies the saved project's country/adoption basis into the advanced engineering module. Its analytical input remains a separately authored dataset; the import warning requires review of that dataset against the chosen project. Changing basis hides stale reports until regeneration.

Each combination retains its source case factors, clause, purpose and either collapse or short-term-serviceability family. The generated frame retains both families; users must review and select the intended combinations and criteria before assessing resistance or drift. Copying it to the 3D module does not update the original recipe source or result. Neither a reduced-dead factor nor a converged frame constitutes a whole-building stability check.

Reports retain normalized detached source, complete captured basis, declaration issues, generated model, factor traces and exclusions. `verification` is always unverified and `nationalCodeCompliance` remains not-assessed. Restoring a report validates exact source/basis/factor correspondence by deterministic recipe arithmetic, without analyzing a frame or calling a native solver. Reports are not signed evidence or numerical verification.

Earthquake/directional/modal combinations, accidental torsion, seismic/wind hazards, site coefficients, live-load reductions/pattern alternatives, soil/fluid/snow/temperature/construction actions, long-term serviceability and full national-code checks remain unsupported. USA and other countries are not assigned Indian factors. No application, tests, builds, lint/typecheck, previews, native programs or repository calculations were executed. Acceptance requires independent factor fixtures, amendment review, case-mapping/unsupported-basis recovery checks and structural integration benchmarks once execution is authorized.

APIs: `parseNationalLoadRecipeInput`, `generateNationalLoadRecipes`, `validateNationalLoadRecipeReport` (boolean restore-only type guard), and `nationalLoadRecipeExample`.
